BANTUAN SINGKAT

Ada yang ingin
ditanyakan?

Beberapa hal sebelum
mulai mengunduh.

File publik seperti ZIP, PDF, gambar, audio, dan video yang diizinkan untuk diunduh oleh pemilik. Folder dan dokumen asli Google Docs, Sheets, atau Slides belum didukung. DriveBridge tidak melewati izin akses atau batas kuota Google.

Dirancang untuk browser seperti Chrome 109 dan Firefox 115 ESR di Windows 7. Internet Explorer tidak didukung. Sertifikat HTTPS, TLS, dan kondisi browser tetap memengaruhi akses. Pengujian langsung di perangkat Windows 7 masih diperlukan.

Pastikan pemilik memilih Bagikan → Akses umum → Siapa saja yang memiliki link, dan mengizinkan unduhan. Jika kuota Google habis, tunggu dan coba lagi. Transfer lewat server dibatasi sekitar 285 detik; file besar atau koneksi lambat dapat terputus.

Isi file tidak disimpan. Server memproses tautan dan metadata untuk unduhan. Supabase hanya menyimpan penghitung permintaan dan identitas jaringan yang diacak setiap menit untuk membatasi penyalahgunaan. Hosting dan Google dapat mencatat permintaan sesuai kebijakannya.
